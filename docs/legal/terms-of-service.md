## 一、定义与适用范围

### 1.1 HelloMe

HelloMe 是面向普通用户的智能体任务平台。用户可以在 HelloMe 中浏览智能体、选择智能体、发起任务、查看执行过程、管理任务结果和算力消耗。

### 1.2 Hz-Hermes

Hz-Hermes 是与 HelloMe 配套使用的本地执行引擎。部分智能体任务需要通过 Hz-Hermes 在您的设备或网页环境中执行，例如打开网页、访问您授权的平台、读取您授权的文件、生成内容、整理结果等。

### 1.3 智能体

智能体是 HelloMe 提供的场景化任务能力，包括但不限于 GEO 智能体、内容创作智能体、视频生成智能体、销售获客智能体、办公协同类智能体及后续上线的其他智能体。

### 1.4 算力 / Token

算力或 Token 是 HelloMe 服务中用于衡量任务执行资源消耗的计量单位。智能体任务在模型调用、网页分析、文件处理、内容生成、流程执行等过程中可能产生 Token 消耗。

### 1.5 本协议适用范围

本协议适用于 HelloMe 网站、后台、智能体市场、工作台、任务中心、成果中心、充值与算力服务、Hz-Hermes 配对及相关扩展服务。

若某一具体服务存在单独规则、活动说明、页面提示或补充协议，该等规则与本协议共同构成完整协议。若两者不一致，以具体服务的特别规则为准。
