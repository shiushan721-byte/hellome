# HelloMe 游客访问智能体市场与首次登录配对流程方案

## 一、调整目标

智能体市场改为公开可访问页面。

用户不登录也可以浏览智能体市场。

用户点击任何需要操作的功能时，提示登录。

第一次登录后，进入 Hz-Hermes 配对引导页。

完成配对后，进入我的工作台。

核心路径：

```text
游客访问智能体市场
浏览广告位、产品位、智能体卡片
点击启用 / 使用 / 详情 / 继续生成等操作
弹出登录提示
完成登录
进入 Hz-Hermes 配对引导页
完成配对
进入我的工作台
```

## 十一、状态判断

用户状态分为：

```text
visitor：未登录
logged_in_unpaired：已登录未配对
logged_in_paired：已登录已配对
```

动作判断：

```text
visitor + 操作：提示登录
logged_in_unpaired + 操作：进入配对页
logged_in_paired + 操作：执行操作
```

伪代码：

```ts
function handleAgentAction(action, agentId) {
  if (!isLoggedIn) {
    openLoginModal({ action, agentId });
    return;
  }

  if (!isHermesPaired) {
    navigate(`/connect-hermes?agent=${agentId}&action=${action}`);
    return;
  }

  runAgentAction(action, agentId);
}
```
