# HelloMe 智能体市场与我的智能体 Tab 方案

## 1. 方案目标

智能体页面需要同时解决两个问题：

```text
智能体市场：让用户浏览、发现、启用更多智能体
我的智能体：让用户查看、进入、停用已经启用的智能体
```

推荐方案：

> 在智能体页面顶部新增 Tab，用同一个页面切换“智能体市场”和“我的智能体”。两个 Tab 使用一致的卡片式打开方式，不使用抽屉，不跳转到单独管理页。

计费与权益原则：

```text
套餐限制可同时启用的智能体数量
用户可以随时停用智能体并释放名额
任务执行按实际 Token 消耗计费
停用不退还已消耗 Token
```

## 2. 页面结构

路由保持一个：

```text
/app/agents
```

页面顶部结构：

```text
┌──────────────────────────────────────────────┐
│ 智能体                                       │
│ 启用智能体会占用 1 个名额，任务按 Token 消耗   │
├──────────────────────────────────────────────┤
│ [智能体市场] [我的智能体]                     │
├──────────────────────────────────────────────┤
│ 已启用智能体 1 / 1   剩余 Token 183,240       │
│ 当前套餐 体验版       [升级套餐]               │
├──────────────────────────────────────────────┤
│ Tab 内容区                                    │
└──────────────────────────────────────────────┘
```

说明：

- “智能体市场”和“我的智能体”是同级 Tab。
- 不使用右侧抽屉。
- 不新增 `/app/agents/manage`。
- 两个 Tab 都沿用卡片式列表展示。
- 不展示“冷却中”“本月即时更换”等复杂规则。

## 3. Tab 命名

推荐命名：

```text
智能体市场
我的智能体
```

原因：

- “智能体市场”明确表达这里是发现和添加智能体的地方。
- “我的智能体”明确表达这里是用户已经启用、当前属于自己的智能体。
- 比“管理智能体”更自然，不像后台功能。

## 4. 顶部名额信息

Tab 下方保留一个轻量名额信息区，让用户无论在哪个 Tab 都知道当前套餐限制。

展示内容：

```text
已启用智能体：1 / 1
剩余 Token：183,240
当前套餐：体验版
```

按钮：

```text
升级套餐
```

状态文案：

### 4.1 还有空位

```text
你还可以启用 2 个智能体。
```

### 4.2 名额已满

```text
智能体名额已满。如需启用新的智能体，请在“我的智能体”中停用一个，或升级套餐。
```

### 4.3 Token 不足

```text
Token 余额不足，已启用智能体仍会保留。充值后即可继续发起任务。
```

## 5. 智能体市场 Tab

目标：

> 让用户发现和启用智能体。

保留市场原有布局：

```text
推荐榜单
分类筛选
搜索框
智能体卡片列表
```

市场 Tab 展示所有可见智能体，包括：

```text
未启用智能体
已启用智能体
即将开放智能体
套餐不可用智能体
```

### 5.1 市场卡片字段

```text
图标
智能体名称
一句话说明
预计 Token 消耗
状态标签
作者或来源
热度/收藏
主操作按钮
```

### 5.2 未启用且可启用

```text
GEO 智能体
检测品牌在 DeepSeek、豆包、Kimi 等 AI 回答里的可见度。

预计 8,000-30,000 Token
[启用]
```

点击“启用”后弹出启用确认。

### 5.3 已启用

市场里也展示已启用状态，但不放停用操作。

```text
GEO 智能体
状态：已启用

[进入使用]
```

辅助文案：

```text
已启用，可在“我的智能体”中停用或更换。
```

### 5.4 名额已满但未启用

```text
销售获客智能体
状态：名额已满

[去我的智能体]
```

点击后切换到“我的智能体” Tab。

### 5.5 即将开放

```text
自媒体小助手
状态：即将开放

[即将开放]
```

按钮置灰。

### 5.6 套餐不可用

```text
批量数据处理智能体
状态：团队版可用

[升级套餐]
```

## 6. 我的智能体 Tab

目标：

> 展示用户当前已经启用的智能体，并提供进入、停用、查看历史任务等操作。

我的智能体不是抽屉，也不是表格管理页，而是和智能体市场一样的卡片式列表。

展示范围：

```text
已启用智能体
套餐降级后只读的智能体
套餐过期后只读的智能体
```

不展示所有未启用智能体。未启用智能体仍在“智能体市场”中浏览和启用。

### 6.1 我的智能体卡片字段

卡片风格和市场保持一致，但字段更偏使用状态：

```text
图标
智能体名称
一句话说明
当前状态
本月任务数
本月 Token 消耗
最近任务
主操作按钮
次操作按钮
```

### 6.2 已启用智能体卡片

```text
GEO 智能体
检测品牌在 AI 搜索和大模型回答中的可见度。

状态：已启用
本月任务：12 个
本月消耗：238,000 Token
最近任务：HelloMe AI 可见度检测，已完成

[进入使用]
[停用]
```

主按钮：

```text
进入使用
```

次按钮：

```text
停用
```

### 6.3 只读智能体卡片

适用于套餐降级或套餐过期。

```text
自媒体智能体
状态：只读

当前套餐不再包含该智能体名额。
历史任务和结果仍可查看。

[查看历史任务]
[升级套餐]
```

### 6.4 我的智能体空状态

如果用户没有启用任何智能体：

```text
你还没有启用任何智能体

去智能体市场选择一个智能体，开始第一个任务。

[去智能体市场]
```

点击后切换到“智能体市场” Tab。

### 6.5 添加更多智能体轻卡片

如果还有空位，可以在我的智能体卡片列表末尾展示：

```text
添加更多智能体
你还可以启用 2 个智能体。

[去智能体市场]
```

如果名额已满，展示：

```text
智能体名额已满
停用一个已启用智能体，或升级套餐获得更多名额。

[升级套餐]
```

## 7. 启用流程

启用只发生在“智能体市场” Tab。

### 7.1 有空位

弹窗：

```text
启用 GEO 智能体？

你的当前套餐可同时启用 1 个智能体，当前已启用 0 个。
启用后将占用 1 个智能体名额。
该智能体内的任务会按实际 Token 消耗计费。

你可以随时在“我的智能体”中停用并更换智能体。停用不会删除历史任务和结果，已消耗 Token 不会退回。

[取消] [确认启用]
```

启用成功后：

```text
市场卡片状态变为“已启用”
顶部名额从 0 / 1 变为 1 / 1
显示轻提示：GEO 智能体已启用
```

轻提示操作：

```text
[进入使用] [查看我的智能体]
```

点击“查看我的智能体”切换到“我的智能体” Tab，并高亮该卡片。

### 7.2 名额已满

弹窗：

```text
智能体名额已满

你的当前套餐可同时启用 1 个智能体，当前已全部使用。
如需启用新的智能体，请在“我的智能体”中停用一个已启用智能体，或升级套餐。

[去我的智能体] [升级套餐]
```

点击“去我的智能体”切换到“我的智能体” Tab。

## 8. 停用流程

停用只放在“我的智能体” Tab。

原因：

```text
停用是更换当前可用智能体的动作
用户需要先看到自己当前启用了哪些智能体
减少在市场浏览时误停用
```

### 8.1 无执行中任务

弹窗：

```text
停用 GEO 智能体？

停用后会立即释放 1 个智能体名额。
历史任务和结果仍可查看，但你将不能继续发起 GEO 任务、继续生成或重新运行 GEO 历史任务。

已消耗的 Token 不会退回。

[取消] [确认停用]
```

停用后：

```text
我的智能体中移除该卡片
市场卡片变回“启用”
顶部名额更新
```

### 8.2 有执行中任务

如果该智能体还有执行中、等待确认、排队中的任务：

```text
该智能体还有进行中的任务

停用前需要先完成或取消当前任务。已消耗的 Token 会按实际执行情况结算。

[查看任务] [取消任务并停用]
```

如果用户选择“取消任务并停用”：

```text
取消未完成任务
按已产生的实际 Token 结算
停用智能体
立即释放名额
```

## 9. Tab 切换规则

默认进入：

```text
/app/agents -> 智能体市场
```

从首页点击“添加智能体”：

```text
/app/agents?tab=market&mode=add
```

从首页点击“我的智能体”或“管理智能体”：

```text
/app/agents?tab=mine
```

名额已满弹窗点击“去我的智能体”：

```text
切换到我的智能体 Tab
```

启用成功点击“查看我的智能体”：

```text
切换到我的智能体 Tab，并高亮新启用卡片
```

我的智能体空状态点击“去智能体市场”：

```text
切换到智能体市场 Tab
```

## 10. URL 设计

推荐：

```text
/app/agents?tab=market
/app/agents?tab=mine
/app/agents?tab=mine&highlight=geo
/app/agents?tab=market&mode=add
```

不要新增：

```text
/app/agents/manage
```

顶部说明建议：

```text
套餐限制可同时启用的智能体数量。你可以随时停用并更换智能体；任务执行按实际 Token 消耗计费。
```

```text

智能体名额已满。你可以在“我的智能体”中停用一个智能体，或升级套餐获得更多名额。
```

停用说明：

```text
停用后立即释放名额，历史任务和结果仍可查看，已消耗 Token 不会退回。
```

## 12. 数据结构建议

页面数据：

```ts
interface AgentsPageData {
  activeTab: 'market' | 'mine';
  quota: AgentQuotaSnapshot;
  marketAgents: AgentMarketCard[];
  myAgents: MyAgentCard[];
}
```

名额状态：

```ts
interface AgentQuotaSnapshot {
  enabledCount: number;
  enabledLimit: number;
  tokenBalance: number;
  planName: string;
}
```

市场卡片：

```ts
interface AgentMarketCard {
  id: string;
  name: string;
  description: string;
  category: string;
  estimatedTokenMin: number;
  estimatedTokenMax: number;
  status:
    | 'inactive'
    | 'active'
    | 'quota_full'
    | 'plan_unavailable'
    | 'coming_soon';
}
```

我的智能体卡片：

```ts
interface MyAgentCard {
  id: string;
  name: string;
  description: string;
  status: 'active' | 'readonly';
  monthlyTaskCount: number;
  monthlyTokenUsed: number;
  latestTask?: {
    id: string;
    name: string;
    status: string;
    updatedAt: string;
  };
  canDeactivate: boolean;
  deactivateReason?: string;
  runningTaskCount?: number;
}
```

不再需要：

```text
instantSwapUsed
instantSwapLimit
coolingDownCount
slotReleaseAt
cooling_down 状态
```

## 13. 实现优先级

### P0

```text
智能体页面顶部新增“智能体市场 / 我的智能体”Tab
默认打开智能体市场
智能体市场保持现有布局
我的智能体使用同样卡片网格展示已启用智能体
顶部展示已启用智能体数量、剩余 Token、当前套餐
市场卡片支持启用、已启用、名额已满、即将开放状态
我的智能体卡片支持进入使用、停用
停用立即释放名额
```

### P1

```text
启用确认弹窗
停用确认弹窗
执行中任务的取消并停用流程
URL query 控制默认 Tab
启用成功后跳到我的智能体并高亮
```

### P2

```text
智能体搜索
分类筛选记忆
智能体详情页
团队成员使用情况
套餐升级弹窗
```

## 14. 验收标准

完成后应满足：

```text
智能体页面顶部有“智能体市场 / 我的智能体”Tab
用户可以通过 Tab 在市场和我的智能体之间切换
不使用抽屉
不跳转单独管理页面
智能体市场保持原有市场浏览布局
我的智能体使用和市场一致的卡片式布局
我的智能体只展示已启用或只读智能体
用户可以在智能体市场启用智能体
用户可以在我的智能体停用智能体
停用后立即释放名额
不存在冷却期和本月更换次数
名额已满时引导用户切换到我的智能体停用或升级套餐
已启用智能体在市场中有清晰状态
顶部始终展示智能体名额和 Token 状态
```

最终表达：

> 智能体市场负责发现和启用，我的智能体负责使用和停用。套餐只限制同时启用数量；用户可以随时停用更换，平台通过任务 Token 消耗获得收益。
