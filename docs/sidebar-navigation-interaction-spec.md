# HelloMe 侧边导航交互规范

## 一、设计目标

HelloMe 侧边导航参考 LibLibAI 的交互方式。

目标：

```text
展开时清晰展示导航名称和二级菜单
收起时只保留图标，提高内容区域宽度
底部保留常用工具入口
更多菜单以浮层方式展开
游客态和登录态共用同一套导航基础结构
```

## 二、导航整体结构

侧边导航分为四个区域：

```text
顶部品牌区
主导航区
底部快捷入口
更多菜单浮层
```

结构：

```text
┌────────────────────┐
│ Logo + 品牌名 + 收起 │
├────────────────────┤
│ 主导航              │
│ 二级菜单            │
│ 分割线              │
│ 账户/内容/帮助入口   │
│                    │
├────────────────────┤
│ 底部快捷入口         │
│ 更多菜单按钮         │
└────────────────────┘
```

## 三、展开态导航

展开态宽度：

```text
宽度：240-280px
推荐：256px
```

样式：

```text
背景：白色
右侧边框：1px solid #f0f0f0
内边距：14-20px
图标尺寸：20-24px
文字字号：16px
主导航字重：600
二级导航字重：400
```

顶部品牌区：

```text
左侧：HelloMe Logo + HelloMe
右侧：收起按钮
```

收起按钮：

```text
点击后切换为收起态
图标使用左右布局切换图标
```

## 四、收起态导航

收起态宽度：

```text
宽度：72-88px
推荐：80px
```

收起态展示：

```text
Logo 图标
主导航图标
分割线
底部快捷图标
更多菜单图标
```

收起态隐藏：

```text
品牌文字
导航文字
二级菜单文字
外部跳转按钮文案
```

收起态交互：

```text
鼠标悬停图标显示 Tooltip
点击图标进入对应页面
点击有二级菜单的图标时展开浮层菜单
点击顶部 Logo 或展开按钮恢复展开态
```

Tooltip 示例：

```text
我的工作台
智能体市场
任务中心
成果中心
算力中心
设置
```

## 六、导航选中态

```text

圆角：10-12px
高度：48-56px
```

```text
背景：透明
文字：#444444
图标：#444444
```

Hover 态：

```text

```

```text

```

## 七、二级菜单交互

带二级菜单的导航项使用箭头表示展开状态。

展开态：

```text
主项右侧显示下箭头
点击主项展开 / 收起二级菜单
二级菜单左侧显示细竖线
二级菜单缩进显示
```

示例：

```text
智能体市场 ˅
  GEO 营销
  内容创作
  销售获客
  办公协同
  数据分析
  技术工程
```

二级菜单样式：

```text
左侧竖线：1px solid #e5e5e5
左侧缩进：32-40px
菜单间距：18-24px
字号：14-15px
颜色：#666666
选中颜色：#111111
```

收起态：

```text
点击带二级菜单的图标
右侧弹出浮层
浮层内展示二级菜单
```

浮层样式：

```text
背景：白色
圆角：12-16px
阴影：0 12px 32px rgba(0,0,0,0.12)
宽度：220-260px
内边距：12-16px
```

## 十二、移动端导航

移动端不使用常驻侧边栏。

移动端建议：

```text
顶部 Logo + 菜单按钮
点击菜单按钮打开全屏抽屉
抽屉内使用展开态导航结构
底部保留登录 / 打开 Hz-Hermes / 更多
```

抽屉样式：

```text
宽度：100%
背景：白色
从左侧滑入
顶部固定品牌区
底部固定快捷入口
```

## 十三、动画规则

展开 / 收起动画：

```text
宽度变化：180-220ms
缓动：ease-out
文字淡入淡出：120-160ms
```

二级菜单展开：

```text
高度展开：160-200ms
透明度变化：120ms
箭头旋转：160ms
```

更多菜单浮层：

```text
出现：轻微上移 + 透明度
时长：140-180ms
```

## 十六、最终定义

> HelloMe 侧边导航采用可展开和可收起的结构。展开态帮助用户理解完整功能，收起态为工作台释放空间，底部快捷入口和更多菜单承载外部工具、协议、客服和品牌信息。
