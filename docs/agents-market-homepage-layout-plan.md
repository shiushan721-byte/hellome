# HelloMe 智能体市场首页化布局方案

## 一、页面定位

智能体市场用于发现智能体、理解智能体价值、启用智能体。

核心定义：

> 我的工作台负责使用智能体，智能体市场负责发现和启用智能体。

用户进入市场后，先看到推荐场景，再看到产品入口，再进入智能体卡片流。

## 二、整体布局

智能体市场采用首页式布局：

```text
顶部标题区
广告位
产品位
分类导航
智能体卡片流
```

页面结构：

```text
智能体市场

[广告位 Banner]

[产品位 / 场景入口]

[分类导航 + 搜索]

[智能体卡片网格]
```

## 三、顶部标题区

顶部标题区展示：

```text
智能体市场
选择适合你的智能体，启用后会出现在我的工作台。
```

右侧展示用户当前额度：

```text
可启用智能体 1 / 1
剩余 Token 3,000,000
升级套餐
```

额度已满时展示：

```text
可启用智能体 1 / 1
当前套餐已满，可停用一个智能体或升级套餐。
```

## 四、广告位 Banner

广告位放在标题区下方。

广告位用于展示：

```text
主推智能体
新上线智能体
套餐升级
行业场景
运营活动
```

广告位内容结构：

```text
主标题
副标题
标签
主按钮
次按钮
视觉区域
```

示例：

```text
GEO 智能体
检测你的品牌在 AI 回答里的可见度

支持 DeepSeek、豆包、Kimi 等模型检测
预计消耗 8,000-30,000 Token

按钮：
立即启用
查看详情
```

第一版先做 1 个主 Banner。

后续可扩展为：

```text
GEO 智能体主推
自媒体智能体即将开放
销售获客智能体内测
升级套餐解锁更多智能体
```

## 五、产品位 / 场景入口

产品位放在广告位下方。

产品位用于把用户需求翻译成智能体入口。

建议展示 4 到 6 个产品位：

```text
检测品牌 AI 可见度
生成 GEO 优化建议
写公众号文章
分析客户网站
生成销售私信
文章转 PPT
```

每个产品位包含：

```text
图标
标题
一句话说明
推荐智能体
状态
```

示例：

```text
检测品牌 AI 可见度
了解你的品牌是否会被 AI 推荐
推荐：GEO 智能体
按钮：去使用
```

点击逻辑：

```text
对应智能体已启用：打开工作台标签
对应智能体未启用且额度未满：弹出启用确认
对应智能体未启用且额度已满：提示停用已有智能体或升级套餐
对应智能体未开放：显示即将开放 / 预约提醒
```

## 六、分类导航

产品位下方进入市场筛选区。

分类建议：

```text
全部
GEO 营销
内容创作
销售获客
办公协同
品牌增长
数据分析
技术工程
```

右侧放搜索框：

```text
搜索智能体
```

搜索支持：

```text
智能体名称
能力关键词
适用场景
```

## 七、智能体卡片流

智能体卡片网格作为页面主体。

卡片展示字段：

```text
智能体图标
智能体名称
一句话说明
适用场景
预计 Token 消耗
使用人数 / 热度
状态标签
操作按钮
```

状态标签：

```text
已启用
可启用
即将开放
套餐不足
内测中
```

按钮逻辑：

```text
已启用：使用智能体
可启用：启用智能体
即将开放：即将开放
套餐不足：升级套餐
内测中：申请内测
```

卡片布局：

```text
桌面端：每行 3-4 个
平板端：每行 2 个
移动端：每行 1 个
```

## 八、智能体卡片点击逻辑

点击卡片主体：

```text
进入智能体详情页
```

点击卡片按钮：

```text
根据状态执行动作
```

具体逻辑：

```text
已启用：打开我的工作台对应智能体标签
未启用且有额度：弹出启用确认
未启用且额度已满：弹出额度提示
即将开放：展示功能预告
内测中：提交内测申请
```

## 九、启用确认弹窗

启用智能体前展示确认弹窗。

弹窗内容：

```text
启用 GEO 智能体？

当前套餐可启用智能体：1 / 1
启用后会出现在我的工作台顶部标签栏。
你可以随时停用，但正式使用后本月该名额会保留到下个周期释放。
```

按钮：

```text
确认启用
取消
```

额度已满时展示：

```text
当前套餐可启用智能体数量已满

你可以：
停用当前智能体
升级套餐
下个周期更换
```

按钮：

```text
去管理已启用智能体
升级套餐
取消
```

## 十、智能体详情页

详情页从市场卡片进入。

详情页结构：

```text
顶部：智能体名称 + 状态 + 启用/使用按钮
适合谁
能做什么
需要输入什么
执行过程
最终交付物
预计 Token 消耗
常见任务模板
```

按钮逻辑：

```text
未启用：启用智能体
已启用：使用智能体
即将开放：预约提醒
内测中：申请内测
```

## 十一、已启用智能体展示

已启用状态直接融合在市场卡片里。

展示规则：

```text
卡片右上角显示：已启用
卡片按钮显示：使用智能体
顶部额度卡展示已启用数量
我的工作台集中展示和使用已启用智能体
```

顶部额度卡点击后可弹出已启用智能体列表：

```text
GEO 智能体
本月 Token 消耗
使用次数
打开工作台
停用
```

## 十二、未配对 Hz-Hermes 状态

未配对 Hz-Hermes 时，市场页可浏览，启用和使用受限。

顶部提示：

```text
使用智能体前，请先配对 Hz-Hermes

HelloMe 负责发起任务，Hz-Hermes 负责在你的电脑和网页环境中执行。
```

按钮：

```text
下载 Hz-Hermes
一键配对
```

智能体卡片按钮显示：

```text
先配对后启用
```

点击后进入配对流程。

## 十五、最终定义

> 智能体市场首页化后，首屏负责推荐和引导，产品位负责把用户需求翻译成智能体入口，卡片流负责完整展示所有可启用智能体。我的工作台负责使用，智能体市场负责发现和启用。
