# HelloMe 登录后首页功能调整方案

## 1. 调整背景

HelloMe 的套餐逻辑已经调整为：

```text
套餐包含 Token 额度
套餐限制可启用智能体数量
任务执行按实际 Token 消耗
```

因此登录后首页不应该再无差别展示所有智能体，而应该以用户已经启用的智能体为核心。

新的首页目标：

> 用户进入首页后，优先看到自己已经启用的智能体、可用 Token、智能体名额和最近任务，并能快速继续工作。

## 2. 首页核心原则

### 2.1 已启用优先

首页主区域只重点展示已启用智能体。

原因：

```text
已启用智能体才是用户当前真正可用的能力
符合套餐中的智能体数量限制
减少用户点进不可用智能体后的挫败感
强化“我当前工作台里有哪些工具”的感觉
```

### 2.2 未启用智能体不消失

未启用智能体不应该完全隐藏，但不作为首页主体。

建议放在：

```text
智能体名额卡片中的“添加智能体”
首页底部的“可添加智能体”
智能体广场页面
```

### 2.3 首页不是智能体广场

首页负责：

```text
当前可用能力
快速发起任务
继续任务
查看用量
查看智能体名额
```

智能体广场负责：

```text
发现更多智能体
启用或停用智能体
查看套餐限制
升级套餐
```

## 3. 首页推荐布局

```text
┌──────────────────────────────────────────────┐
│ 顶部：今天想让哪个智能体开始工作？             │
│ [ 输入任务目标，系统从已启用智能体中推荐... ]   │
├──────────────────────────┬───────────────────┤
│ 已启用智能体              │ 智能体名额          │
│ [GEO 智能体]              │ 2 / 3              │
│ [自媒体智能体]            │ [添加智能体]         │
├──────────────────────────┼───────────────────┤
│ 最近任务                  │ Token 用量          │
│ GEO 检测 进行中            │ 剩余 183,240 Token  │
│ 公众号文章 已完成           │ 本月已用 316,760     │
├──────────────────────────────────────────────┤
│ 可继续操作 / 推荐下一步                       │
└──────────────────────────────────────────────┘
```

## 4. 首页模块设计

### 4.1 自然语言任务输入

首页顶部保留自然语言任务输入，但推荐范围应从“所有智能体”改成“已启用智能体”。

文案：

```text
今天想让哪个智能体开始工作？
```

输入框 placeholder：

```text
描述你的目标，系统会从已启用智能体中推荐合适的执行方式
```

示例：

```text
帮我检测 HelloMe 在 AI 搜索里的可见度
把这篇文章改成公众号风格
分析这个客户网站并生成销售私信
```

匹配逻辑：

```text
如果匹配到已启用智能体：推荐该智能体并允许开始
如果匹配到未启用智能体：提示需要先启用
如果没有合适智能体：引导去智能体广场添加
```

未启用提示示例：

```text
这个任务适合“销售获客智能体”，但你还没有启用它。
当前可启用智能体：2 / 3
[启用销售获客智能体] [去智能体广场]
```

名额已满提示：

```text
这个任务适合“销售获客智能体”，但你的智能体名额已满。
你可以停用一个已启用智能体，或升级套餐。
[管理智能体] [升级套餐]
```

### 4.2 已启用智能体区

这是首页最重要的区域。

标题：

```text
已启用智能体
```

副标题：

```text
这些智能体当前可直接发起任务
```

智能体卡片字段：

```text
智能体名称
一句话说明
本月任务数
本月 Token 消耗
最近一次任务状态
常用任务模板
进入按钮
```

示例：

```text
GEO 智能体
检测品牌在 AI 搜索和大模型回答中的可见度

本月任务：12
本月消耗：238,000 Token
最近任务：HelloMe AI 可见度检测，已完成

[开始新任务] [查看最近结果]
```

卡片操作：

```text
开始新任务
查看最近结果
查看任务历史
```

不建议在首页卡片上放“停用”主按钮。

原因：

```text
首页是工作入口，不是管理入口
停用属于管理行为，放在智能体广场或套餐用量页更合适
避免用户误操作
```

可以在更多菜单里放：

```text
管理智能体
```

跳转到智能体广场或智能体管理页。

### 4.3 智能体数量卡片

首页必须展示智能体名额卡片，让用户知道套餐限制和当前占用。

标题：

```text
智能体名额
```

展示：

```text
已启用 2 / 3
```

内容：

```text
当前套餐：专业版
本月即时更换：1 / 1
冷却中：0
```

按钮：

```text
[添加智能体]
[管理智能体]
```

不同状态文案：

#### 还有空位

```text
你还可以启用 1 个智能体。
```

按钮：

```text
[添加智能体]
```

#### 名额已满

```text
智能体名额已满。如需使用新的智能体，请停用一个已启用智能体或升级套餐。
```

按钮：

```text
[管理智能体] [升级套餐]
```

#### 有冷却中名额

```text
有 1 个名额正在冷却，将在 18 小时后释放。
```

按钮：

```text
[查看冷却详情]
```

### 4.4 Token 用量卡片

首页保留 Token 用量概览，但不要和智能体数量混在一起。

标题：

```text
Token 用量
```

展示：

```text
剩余 Token：183,240
本月已用：316,760
本月额度：500,000
使用进度：63%
```

低余额提示：

```text
剩余 Token 低于 10%，建议及时充值，避免任务中断。
```

按钮：

```text
[查看用量] [充值 Token]
```

### 4.5 最近任务

最近任务应优先展示已启用智能体产生的任务。

字段：

```text
任务名称
智能体
状态
Token 消耗
更新时间
操作
```

操作：

```text
继续
查看结果
重新运行
```

如果任务所属智能体已停用：

```text
查看结果：允许
重新运行：需要重新启用该智能体
继续生成：需要重新启用该智能体
```

提示：

```text
该任务所属智能体已停用，重新运行前需要重新启用。
```

### 4.6 推荐下一步

首页可以增加“推荐下一步”，但推荐应基于已启用智能体和最近结果。

示例：

```text
基于上次 GEO 报告，继续生成官网 FAQ
基于上次文章，继续生成小红书改写版
基于客户分析结果，继续生成跟进邮件
```

如果对应智能体未启用：

```text
需要启用自媒体智能体后继续
```

## 5. 空状态设计

### 5.1 新用户未启用任何智能体

首页不能空白，应该引导选择第一个智能体。

布局：

```text
欢迎来到 HelloMe
先启用一个智能体，开始你的第一个任务。

当前套餐：体验版
可启用智能体：0 / 1

推荐启用：
[GEO 智能体] [自媒体智能体] [销售获客智能体]
```

推荐优先级：

```text
GEO 智能体优先
自媒体智能体
销售获客智能体
```

按钮：

```text
[启用 GEO 智能体]
[查看全部智能体]
```

### 5.2 已启用但没有任务

```text
你已经启用了 GEO 智能体。
从一个任务开始：检测品牌 AI 可见度。

[开始 GEO 检测]
```

### 5.3 名额已满但想添加

```text
你的智能体名额已满。
当前已启用：GEO 智能体、自媒体智能体、销售获客智能体。

如需添加新的智能体，可以停用一个已启用智能体，或升级套餐。
```

按钮：

```text
[管理智能体] [升级套餐]
```

## 6. 首页和智能体广场的关系

首页：

```text
展示已启用智能体
发起任务
继续任务
查看 Token 和名额概览
```

智能体广场：

```text
展示全部智能体
启用智能体
停用智能体
查看冷却状态
升级套餐
```

不要让首页承担完整智能体管理能力。

首页可以提供入口：

```text
添加智能体
管理智能体
```

但具体启用、停用、冷却详情放到智能体广场或智能体管理页。

## 7. 首页数据结构建议

首页需要聚合以下数据：

```ts
interface HomeDashboardData {
  usage: UsageSnapshot;
  agentQuota: AgentQuotaSnapshot;
  enabledAgents: EnabledAgentSummary[];
  recentTasks: TaskSummary[];
  recommendedActions: RecommendedAction[];
}
```

智能体名额：

```ts
interface AgentQuotaSnapshot {
  enabledCount: number;
  enabledLimit: number;
  instantSwapUsed: number;
  instantSwapLimit: number;
  coolingDownCount: number;
  nextSlotReleaseAt?: string;
}
```

已启用智能体摘要：

```ts
interface EnabledAgentSummary {
  agentId: string;
  name: string;
  description: string;
  monthlyTaskCount: number;
  monthlyTokenUsed: number;
  latestTask?: {
    id: string;
    name: string;
    status: TaskStatus;
    updatedAt: string;
  };
  templates: Array<{
    id: string;
    title: string;
  }>;
}
```

推荐下一步：

```ts
interface RecommendedAction {
  id: string;
  title: string;
  agentId: string;
  sourceTaskId?: string;
  estimatedTokenMin: number;
  estimatedTokenMax: number;
  requiresActivation: boolean;
}
```

## 8. 路由与跳转

首页入口：

```text
/app
```

点击已启用智能体：

```text
/app/agents/:agentId
```

点击添加智能体：

```text
/app/agents?mode=add
```

点击管理智能体：

```text
/app/agents?tab=enabled
```

点击查看用量：

```text
/app/usage
```

点击最近任务：

```text
/app/tasks/:taskId
```

## 9. 当前首页功能修改清单

### 9.1 移除或弱化

```text
无差别推荐所有智能体
所有任务模板平铺
未启用智能体直接开始任务
用“剩余任务次数”作为主指标
```

### 9.2 新增或强化

```text
已启用智能体卡片
智能体名额卡片
Token 用量卡片
从已启用智能体中推荐执行方式
未启用智能体的启用提示
名额已满提示
冷却中名额提示
停用智能体后的历史任务只读提示
```

## 10. 推荐首页模块优先级

### P0

```text
已启用智能体区
智能体名额卡片
Token 用量卡片
最近任务
新用户未启用智能体空状态
```

### P1

```text
自然语言任务输入根据已启用智能体推荐
推荐下一步
冷却中名额倒计时
名额已满时的管理入口
```

### P2

```text
首页个性化排序
基于历史任务的智能推荐
团队成员维度的智能体使用情况
```

## 11. 首页验收标准

完成后首页应满足：

```text
用户可以清楚看到当前启用了哪些智能体
用户可以清楚看到智能体名额用了多少
用户可以知道还能不能添加智能体
用户可以从已启用智能体快速发起任务
用户不会在首页直接误用未启用智能体
Token 用量和智能体名额是两个独立但并列的概览
新用户没有启用智能体时，有清晰的第一步引导
历史任务不因智能体停用而消失
```

最终首页表达：

> 这里是你当前已启用智能体的工作台。先看可用智能体，再看名额和 Token，然后继续任务或开始新任务。
