# HelloMe 成果中心产品方案

## 一、产品定位

成果中心用于集中管理所有智能体生成的最终交付物。

核心定义：

> 任务中心看过程，成果中心拿结果。

成果中心保存：

- 文档
- 表格
- PPT
- 网页/代码
- 图片
- 视频
- 其他智能体生成文件

## 二、导航入口

左侧导航增加：

```text

```

```text

## 九、继续生成能力

```

## 十七、空状态

没有成果时展示：

```text
这里会保存智能体为你生成的成果

当你使用 GEO 智能体生成报告、使用自媒体智能体生成文章，
或使用销售获客智能体生成客户分析后，成果会自动出现在这里。
```

按钮：

```text
去我的工作台
打开智能体市场
```

未配对 Hz-Hermes 时展示：

```text
先配对你的 Hz-Hermes 引擎

HelloMe 负责发起任务和保存成果，Hz-Hermes 负责在你的电脑和网页环境中执行。
完成配对后，你使用智能体生成的报告、文档和表格都会保存在这里。
```

按钮：

```text
下载 Hz-Hermes
一键配对
```

## 二十、最终定义

> 成果中心是 HelloMe 管理智能体交付物的地方。用户可以按成果类型、来源智能体、时间和格式快速找到结果，并继续让智能体基于已有成果往下生成。
