# HelloMe 项目上下文方案

## 一、核心结论

HelloMe 使用智能体前必须选择或新建项目。

项目是 HelloMe 的业务上下文容器，用来：

```text
隔离 Hz-Hermes 记忆
复用项目资料
自动预填智能体表单
沉淀任务结果
让多个智能体围绕同一个业务目标协同
```

不再支持临时任务。

## 二、使用流程

```text
点击“使用智能体”
  ↓
弹窗选择已有项目 / 新建项目
  ↓
进入智能体页面
  ↓
读取项目资料
  ↓
匹配当前智能体表单字段
  ↓
可直接复用的字段自动填写
  ↓
可推断字段给推荐
  ↓
缺失字段留空
  ↓
用户确认后发起任务
  ↓
任务结果反写项目资料
```

## 三、项目资料

第一版项目资料包括：

```text
项目名称
品牌名
官网 URL
产品 / 服务介绍
目标客户
核心关键词
竞品
品牌卖点
常用语气
补充说明
历史任务
历史成果
```

## 四、智能体页面规则

智能体页面不提供项目切换。

项目选择发生在点击“使用智能体”之后、进入智能体页面之前。

进入智能体页面后：

```text
页面显示当前项目名称
系统根据项目资料自动预填字段
用户可以修改当前任务字段
用户确认后发起项目任务
```

## 五、字段匹配规则

字段分为三类：

```text
直接复用字段
智能推荐字段
用户选择字段
```

直接复用字段：

```text
品牌名
官网 URL
产品 / 服务介绍
目标客户
核心关键词
竞品
```

智能推荐字段：

```text
产品卖点
内容方向
视频主题
销售切入点
FAQ 问题
用户痛点
```

用户选择字段：

```text
视频类型
视频风格
生成平台
检测深度
发布渠道
预算
时长
语气
```

## 六、任务中心

任务中心不再区分临时任务。

任务列表展示：

```text
任务名称
使用智能体
所属项目
状态
创建时间
执行耗时
Token 消耗
操作
```

历史旧任务如果没有项目，显示：

```text
未归属项目
```

新任务必须有项目。

## 七、成果中心

成果中心不再区分临时成果。

成果列表展示：

```text
成果名称
成果类型
来源智能体
所属项目
来源任务
生成时间
Token 消耗
操作
```

新成果必须归属项目。

## 八、Hermes 上下文规则

Hermes 上下文按项目隔离。

上下文边界：

```text
userId + projectId + agentId
```

规则：

```text
不同项目之间记忆隔离
同一项目下可共享项目资料
同一项目下不同智能体按需读取项目资料
同一项目 + 同一智能体可以延续项目内记忆
```

## 九、数据模型建议

Project：

```text
id
userId
name
description
brandName
websiteUrl
productIntro
targetAudience
keywords
competitors
sellingPoints
tone
notes
createdAt
updatedAt
```

Task：

```text
projectId
taskScope: project
```

Artifact / Result：

```text
projectId
```

HermesExecution：

```text
projectId
contextKey = userId + projectId + agentId
```

## 十、第一版实现范围

P0 必做：

```text
项目模型
创建项目
项目资料编辑
点击使用智能体时弹项目选择
选择已有项目 / 新建项目
进入智能体页面后自动预填资料
任务必须归属项目
成果必须归属项目
任务中心展示所属项目
成果中心展示所属项目
Hermes 按 projectId 隔离上下文
任务结果反写项目资料
```

P1 再做：

```text
项目详情页
项目内任务时间线
项目内成果聚合
项目资料版本记录
项目归档
项目搜索
```

## 十一、最终定义

> 项目是 HelloMe 使用智能体的前置上下文。用户点击“使用智能体”后必须选择或新建项目，再进入智能体页面。项目负责资料复用、任务沉淀和 Hermes 记忆隔离。
