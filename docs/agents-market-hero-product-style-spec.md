# 智能体市场顶部广告位与产品位前端样式规范

## 一、适用范围

本文档用于规范智能体市场首页化改版中的两个区域：

```text
顶部广告位
横向产品位 / 推荐智能体位
```

页面整体结构：

```text
智能体市场

顶部广告位

横向产品位 / 推荐智能体位

分类导航 + 搜索

智能体卡片流
```

## 二、顶部广告位

### 2.1 区域定位

顶部广告位用于承载市场页首屏推荐。

展示内容：

```text
主推智能体
主推任务场景
新功能
运营活动
算力充值活动
即将开放能力
```

### 2.2 布局结构

顶部广告位采用横向多卡片布局。

桌面端布局：

```text
左侧 1 张大 Banner
右侧 3 张中 Banner
```

比例建议：

```text
大 Banner：约 36%
中 Banner：每张约 20%
卡片间距：8-12px
区域高度：180-220px
```

结构示例：

```text
┌──────────────────────────────┬──────────────────┬──────────────────┬──────────────────┐
│ 主推大 Banner                 │ 中 Banner 1       │ 中 Banner 2       │ 中 Banner 3       │
│                              │                  │                  │                  │
└──────────────────────────────┴──────────────────┴──────────────────┴──────────────────┘
```

移动端布局：

```text
横向滑动卡片
第一张为主推 Banner
后续为中 Banner
```

### 2.3 大 Banner 样式

大 Banner 用于最重要推荐。

尺寸：

```text
宽度：占容器 34%-38%
高度：180-220px
圆角：6-8px
```

视觉风格：

```text
深色背景
真实图片或生成图作为背景
左侧文案
右侧视觉图
文字使用白色
背景可加黑色透明遮罩
```

内容结构：

```text
小标题
主标题
补充说明
活动时间 / 标签
主视觉
```

示例：

```text
「GEO 检测」AI 品牌可见度
检测你的品牌是否会被 AI 推荐
支持 DeepSeek、豆包、Kimi 等模型
```

### 2.4 中 Banner 样式

中 Banner 用于展示重点能力。

尺寸：

```text
宽度：占容器 19%-22%
高度：180-220px
圆角：6-8px
```

视觉风格：

```text
深色背景
简洁主视觉
左侧或左上角文案
右侧视觉元素
可放一个轻量按钮
```

内容结构：

```text
标题
一句话说明
按钮 / 标签
主视觉
```

示例：

```text
图片视频生成
快速创作图片、视频
立即生成
```

对应到 HelloMe 可改为：

```text
GEO 优化建议
自动生成官网内容优化方向
立即使用
```

```text
自媒体创作
公众号、小红书、视频号内容生成
即将开放
```

```text
销售获客
分析客户网站并生成触达话术
内测中
```

### 2.5 顶部广告位交互

点击规则：

```text
点击 Banner 主体：进入对应智能体详情或专题页
点击主按钮：执行启用 / 使用 / 预约 / 充值
```

按钮状态：

```text
已启用：立即使用
未启用：启用智能体
未配对：先配对 Hz-Hermes
Token 不足：充值算力
未开放：即将开放
```

### 2.6 顶部广告位内容建议

第一版建议展示 4 个 Banner：

```text
主推：GEO 智能体
中位 1：GEO 优化建议
中位 2：自媒体智能体
中位 3：销售获客智能体
```

示例：

```text
GEO 智能体
检测你的品牌在 AI 回答里的可见度
预计消耗 8,000-30,000 Token
启用智能体
```

```text
GEO 优化建议
根据检测结果生成 FAQ、LLMs.txt、Schema
立即使用
```

```text
自媒体智能体
生成公众号、小红书、视频号内容
即将开放
```

```text
销售获客智能体
分析客户网站，生成私信和邮件
内测中
```

## 三、横向产品位 / 推荐智能体位

### 3.1 区域定位

横向产品位用于展示可快速进入的任务场景或推荐智能体。

它位于顶部广告位下方。

展示内容：

```text
推荐智能体
热门任务场景
新上线能力
即将开放能力
```

### 3.2 区域标题

区域标题结构：

```text
主标题
辅助标签
更多入口
```

示例：

```text
一键使用热门智能体
GEO 智能体已开放，内容创作与销售获客即将上线
查看更多
```

样式建议：

```text
主标题：14-16px，字重 600
辅助标签：浅色胶囊标签，12px
更多入口：右箭头或文字链接
```

### 3.3 横向卡片布局

产品位采用横向小卡片列表。

桌面端：

```text
一行展示 6-8 个
超出横向滚动
卡片高度 54-64px
卡片宽度 200-260px
卡片间距 8px
```

移动端：

```text
横向滑动
一屏展示 1.5-2.2 个
```

结构示例：

```text
┌────────────┐ ┌────────────┐ ┌────────────┐ ┌────────────┐
│ GEO 智能体 │ │ 自媒体助手 │ │ 销售获客   │ │ FAQ 生成   │
└────────────┘ └────────────┘ └────────────┘ └────────────┘
```

### 3.4 小卡片内容结构

每个小卡片包含：

```text
左侧图标
标题
状态标签
一句话说明
```

可选：

```text
角标
边框颜色
背景浅色
```

卡片示例：

```text
图标
GEO 智能体        已开放
检测品牌 AI 可见度
```

```text
图标
自媒体小助手      即将开放
公众号、小红书内容生成
```

### 3.5 小卡片视觉样式

基础样式：

```text
背景：白色或极浅色
边框：1px solid
圆角：6px
内边距：10-12px
阴影：轻微或无阴影
```

不同状态使用不同弱色边框：

```text
已开放：蓝色 / 绿色弱边框
已启用：绿色弱背景
即将开放：灰色弱边框
内测中：黄色弱边框
推荐：蓝色弱边框
```

状态标签：

```text
已启用
已开放
即将开放
内测中
推荐
```

标签样式：

```text
高度：18-20px
字号：10-11px
圆角：999px
背景：对应状态浅色
文字：对应状态深色
```

### 3.6 小卡片交互

点击卡片：

```text
已启用：打开我的工作台对应智能体标签
未启用：启用智能体并打开工作台标签
未配对：进入 Hz-Hermes 配对流程
即将开放：展示功能预告
内测中：展示申请内测
```

Hover 状态：

```text
卡片轻微上浮 1-2px
边框颜色加深
阴影增强
鼠标为 pointer
```

Active 状态：

```text
轻微压低
阴影减弱
```

## 四、页面间距规范

整体容器：

```text
最大宽度：不限制或 1440-1600px
左右内边距：24-32px
顶部间距：24px
```

模块间距：

```text
标题区到广告位：16px
广告位到产品位：28-32px
产品位到分类导航：24-28px
分类导航到卡片流：16-20px
```

卡片间距：

```text
顶部广告位卡片间距：8-12px
产品位卡片间距：8px
智能体卡片网格间距：16-20px
```

## 五、颜色与质感

顶部广告位：

```text
以深色背景为主
使用真实图、生成图或产品视觉图
文字使用白色
可使用黑色透明遮罩增强可读性
```

横向产品位：

```text
以浅色卡片为主
不同状态使用弱色边框
整体保持轻、密、可扫读
```

推荐状态色：

```text
已启用：绿色
已开放：蓝色
推荐：蓝色
即将开放：灰色
内测中：黄色
Token 不足：红色提示
```

## 六、响应式规则

桌面端：

```text
顶部广告位：1 大 + 3 中
产品位：横向展示 6-8 个
```

平板端：

```text
顶部广告位：横向滚动
产品位：横向滚动
```

移动端：

```text
顶部广告位：横向滚动卡片
第一张卡片宽度约 80%-88%
产品位卡片宽度约 72%-82%
隐藏复杂副文案
保留标题、状态和核心按钮
```

## 七、第一版实现范围

第一版做：

```text
顶部 4 张广告位
1 张主推大 Banner
3 张中 Banner
横向产品位 8 个
状态标签
点击跳转逻辑
未配对状态拦截
Token 不足提示
移动端横向滚动
```

第一版暂后置：

```text
Banner 自动轮播
个性化推荐
广告后台配置
复杂动效
用户行为推荐排序
AB 测试
```

## 八、最终效果

智能体市场首屏最终形成：

```text
上方：高视觉冲击力广告位
中间：轻量横向产品位
下方：分类筛选与智能体卡片流
```

目标体验：

> 用户进入智能体市场后，先被推荐内容吸引，再通过产品位快速理解能做什么，最后通过卡片流浏览和启用更多智能体。
